# Aldune demo

**[▶ Open the live demo](https://ethanjordanschwartz.github.io/Aldune/demo/tour.html)**

GitHub shows the files in this folder as code. Use the link above to open the working demo in your browser. It opens straight into a fictional sample company, and no sign-in is needed.

- `tour.html`: portfolio tour. It loads the sample company automatically.
- `index.html`: the full single-file app. Sign in with `demo@aldune.dev` / `AlduneDemo2026`.
